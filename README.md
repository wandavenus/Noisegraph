## About

**Noisegraph** is an Android music player project designed around a modern interface and a more immersive listening experience. It brings together music playback and carefully crafted player UI in one place.

## Highlights

- **Modern player experience** — a polished interface inspired by contemporary music apps.
- **Now Playing** — a dedicated space for the track you're listening to.
- **Local music** — listen to music available on your Android device.
- **Playback-focused design** — UI and controls designed to keep listening front and center.
- **Ongoing development** — features and refinements evolve between releases.

> Noisegraph is actively evolving. The exact feature set may vary between builds.

## Download

Get the latest available Android build from **[GitHub Releases](https://github.com/wandavenus/Noisegraph/releases/latest)**.

1. Open the latest release.
2. Download the APK asset.
3. Install it on your Android device. If Android asks, allow installation from the app you're using to open the APK.

### Compatibility

- **Platform:** Android
- **Build architecture:** ARM64 (arm64-v8a)
- **Package format:** APK

Only install APKs you trust. Back up anything important before installing a development build.
