What is Noisegraph?

Noisegraph is an Android music player project focused on local music playback, a modern Now Playing experience, and playback transitions.

How do I download it?

Open the latest GitHub Release, download the APK asset, and install it on your Android device. Review the release notes before installing a build.

Which devices are supported?

The published build targets Android on ARM64 (arm64-v8a). Compatibility can vary by release, so check the notes attached to the build you download.

Is Noisegraph still in development?

Yes. The feature set can change between builds. Follow the repository for development updates and use GitHub Issues to report a reproducible bug or suggest an improvement.

Where can I report a problem?

Open a GitHub Issue and include steps to reproduce the problem, your Android version, device model, and any useful logs or screenshots.
